# Alien Field Notes — The Two Day Earth Review

One line, under 200 characters: a review of planet Earth left by an alien tourist.

This program writes the review to `/output/entry.txt` (170 characters, no trailing
newline):

> Two stars. The locals ask 'how are you?' then walk away before the answer, and pay to sit in the dark watching a bigger rectangle. The sunsets are worth the trip, though.

Run it with `node main.ts` (Node 22).
